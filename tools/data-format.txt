売上入力帳 データファイル（.json）の中身

このファイルはテキスト形式（JSON・文字コードUTF-8）です。メモ帳でも開いて読めます。
アプリが使えなくなったときは、同じフォルダの「売上データ_CSV変換.html」でCSV（Excelで開ける形式）に変換できます。

■ 全体
  customers : 取引先の一覧
  entries   : 売上の明細（1件ずつ）
  past      : 明細のない過去の月別合計（旧Excelから引き継いだ平成27年〜令和2年分）
  seq / updatedAt / v : アプリが使う管理用の値

■ customers（取引先）
  name   : 取引先名
  hidden : true なら入力画面に出さない取引先

■ entries（明細）
  y : 計上する年（西暦）
  m : 計上する月
  d : 日付（例 2026-11-20）。メモ（例 7/中）や空欄（null）のこともある
  c : 取引先名
  a : 金額（税抜・円）。マイナスは値引き・返品
  n : 備考
  id : 通し番号
  t : 入力した日時（1970年1月1日からのミリ秒）。旧Excelから引き継いだ行にはない
  u : 最後に直した日時（同上）

■ past（過去の月別合計）
  y : 年（西暦）
  m : 月
  t : その月の売上合計（税抜・円）

■ 集計のしかた
  月の売上 ＝ その年・月（y・m）の entries の a の合計 ＋ 同じ年・月の past の t
